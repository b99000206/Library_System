# My Dashboard App

這是我的儀表板應用程式，使用 Nuxt.js、Shadcn 和 UnoCSS 構建。

## 關聯
`.degit` 資料夾：此資料夾是通過 `degit` 工具下載模板時自動創建的，包含模板的元數據，並且與本應用程式的模板下載過程相關。所以`my-dashboard-app`和`.degit`有關連

## Quick Start

```bash [Terminal]
npx degit dianprata/nuxt-shadcn-dashboard my-dashboard-app
cd my-dashboard-app
pnpm i # If you don't have pnpm installed, run: npm install -g pnpm
```

## Contributing

1. Clone this repository.
2. Install dependencies `pnpm install`.
3. Use `pnpm run dev` to start dev server.
